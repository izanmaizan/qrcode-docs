# QR Code Generator

Alat baris perintah berbasis Node.js untuk membuat QR code dari teks atau URL, dengan logo dan label teks.

## Kegunaan

- Membuat QR code dari teks atau URL apa pun.
- Logo di tengah QR dan label teks di atas atau bawah.
- Mode batch untuk banyak QR dalam satu sesi.

## Tech stack

| Lapis | Teknologi |
|---|---|
| Runtime | Node.js |
| Pustaka | qrcode, jimp |

## Alur singkat

1. Jalankan alat, pilih mode tunggal atau batch.
2. Isi konten, logo, dan posisi label.
3. Berkas PNG disimpan dengan nama yang ditentukan.
